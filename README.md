# 📖 About

**Mobile Online Shop** is an ASP.NET storefront for mobile products.

A visitor sees the main groups, opens the products in a group, and adds one to the basket. A member can save the basket and confirm the order. Search works by group and by product name. The admin side defines groups, products, users, and sales.

> **Tagline:** *An ASP.NET mobile shop with products, a basket, users, and an admin desk.*

The PHP store in [Online Shop](https://github.com/sadra-hatami/Online-Shop) is a separate project.

---

# 🚀 Why This Project?

A shop needs a storefront and a desk behind it.

This one keeps that split:

- Groups and products on the public side
- A basket that can be edited, saved, and confirmed
- Signup before the final order
- An admin path for groups, products, users, and sales

---

# 👥 Two Sides

| Side | Role |
|---|---|
| Storefront | Groups, products, search, basket, signup |
| Admin | Groups, products, users, and sales |

A visitor can hold a basket before signup. Saving and confirming the order need a member account.

# ▶️ How to Open

1. Clone the repository.
2. Open the site in Visual Studio.
3. Point `Web.Config` at a local SQL Server database.
4. Run `Default.aspx`.

Do not commit `.mdf` or `.ldf` files, and do not leave a real password in `Web.Config`.
